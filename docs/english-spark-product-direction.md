# English Spark — Student-first product direction

## Product principle

Every product decision must improve one of two outcomes:

1. Make the student want to continue learning.
2. Make it materially faster for a workspace member to create a good student experience.

The product has two intentionally different surfaces:

- **Studio**: calm, fast, content-creation focused.
- **Student Experience**: immersive, playful, mobile-first.

## Student identity model

English Spark keeps frictionless guest play as the default for links and live classroom activities. Students do **not** need email/password accounts to join an activity.

A future persistent Student Profile can be added as an optional layer for long-term progress across devices (class code + username/PIN or QR), without removing guest play.

## Content creation model

The Question Bank is a first-class product capability, not an advanced technical detail. Activity creation exposes three paths:

1. Create one question quickly.
2. Reuse multiple questions from the Question Bank.
3. Create/import many questions in one operation.

## SaaS model

The platform is multi-tenant. Each customer owns a Workspace/Tenant with isolated content and memberships. PlatformAdmin manages plans, subscriptions, usage and customers globally.
