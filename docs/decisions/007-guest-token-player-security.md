# ADR 007 — أمان رموز الضيوف (Guest Tokens) في واجهة اللاعب

**الحالة:** Accepted
**التاريخ:** 2026-08-05

## السياق

Phase 4 تتيح للطلاب الانضمام إلى جلسات الاختبار عبر رمز انضمام عام (`JoinCode`) **بدون حساب مستخدم**. نحتاج آلية تربط طلبات اللاعب اللاحقة (بدء المحاولة، إرسال الإجابات، الإنهاء) بالمشارك الصحيح دون تسجيل دخول، مع حماية من التخمين والسرقة وإعادة الاستخدام.

## القرار

- **توليد الرمز:** 256-bit عشوائي عبر `RandomNumberGenerator.GetBytes(32)`، يُرمَّز Base64Url. لا يُشتق من أي بيانات قابلة للتخمين.
- **التخزين:** **الهاش فقط** — `SHA-256(token)` في عمود `SessionParticipants.GuestTokenHash`. الرمز الخام لا يُخزن أبدًا في قاعدة البيانات ولا في السجلات.
- **المقارنة:** عند كل طلب لاعب، يُحسب هاش الرمز الوارد ويُقارن بالمخزن بمقارنة **ثابتة الزمن** (`CryptographicOperations.FixedTimeEquals`) لمنع هجمات التوقيت.
- **النقل:** الرمز يُرسل للعميل مرة واحدة في استجابة `join`، ويُخزن في كوكي **HttpOnly**:
  - Production: `__Host-tp-guest` (Secure + HttpOnly + SameSite=Strict + Path=/ — بادئة `__Host-` تمنع التجاوز من نطاقات فرعية).
  - Development/Testing: `tp-guest` (بدون بادئة `__Host-` لأن localhost لا يدعم Secure دائمًا).
- **Rate Limiting:** نقاط اللاعب (`join`, `attempts`, `answers`, `finish`) محدودة المعدل عبر `RateLimiter` لكل IP + JoinCode لإبطاء التخمين على رموز الانضمام.
- **الصلاحية:** الرمز مرتبط بمشارك واحد في جلسة واحدة؛ إنهاء الجلسة أو إلغاؤها يجعل المحاولات الجديدة مرفوضة (`SessionNotActive`).

## البدائل

- **JWT موقّع للضيف:** يتطلب إدارة مفاتيح وإبطالًا — أثقل من الحاجة؛ الكوكي + الهاش أبسط وقابل للإبطال بحذف السجل.
- **تخزين الرمز الخام مشفرًا:** التشفير قابل للعكس إذا تسرب المفتاح؛ الهاش أحادي الاتجاه أأمن — والرمز لا يحتاج استرجاعًا.
- **مقارنة نصية عادية (`==`):** تكشف توقيت المقارنة وتسرّب معلومات عن بادئة الرمز — مرفوضة لصالح `FixedTimeEquals`.
- **كوكي بدون HttpOnly + تخزين في localStorage:** يعرّض الرمز لسرقة XSS — مرفوض؛ الكوكي HttpOnly لا تصله JavaScript.

## النتائج

- تسريب قاعدة البيانات لا يكشف رموزًا صالحة (هاشات فقط).
- هجمات التوقيت على المقارنة غير مجدية.
- XSS لا يمكنه قراءة رمز الضيف.
- Rate limiting يجعل تخمين JoinCode (8 أحرف) + رمز الضيف معًا غير عملي.

## قيود

- الكوكي مرتبط بالمتصفح؛ لاعب يغيّر الجهاز يحتاج الانضمام من جديد (بنفس الاسم) — مقبول لأن الاستئناف بعد F5 داخل نفس المتصفح هو السيناريو المستهدف.
- لا يوجد إبطال فردي للرمز دون حذف المشارك — يُؤجل حتى ظهور حاجة فعلية.
