# ADR-009 — توليد الشهادات وOutbox والمشاركة العامة

**الحالة:** Accepted  
**التاريخ:** 2026-08-09

## السياق

إنشاء PDF قد يفشل أو يطول، ولا ينبغي أن يمدد طلب إنهاء الاختبار أو يجعل نجاح المحاولة تابعًا لملف خارجي. وفي الوقت نفسه يجب أن تكون الشهادة مقتصرة على المحاولات الناجحة، قابلة لإعادة المحاولة بلا تكرار، وآمنة عند مشاركتها خارج حساب المعلم. يحتاج رابط ولي الأمر إلى عقد أضيق ومدة صلاحية محددة.

## القرار

1. **الأهلية خادمية:** لا تُنشأ `Certificate` إلا عندما تكون المحاولة مكتملة و`Passed=true`. يوجد قيد فريد على المحاولة، لذلك تكرار طلب الإصدار يعيد السجل نفسه.
2. **Snapshot ثابت:** تحفظ الشهادة وقت الإصدار اسم الطالب وعنوان الاختبار والنسبة ونصوص القالب وألوانه واسم الجهة. تعديل القالب لاحقًا لا يغيّر شهادة سابقة.
3. **Transactional Outbox:** تُحفظ `Certificate` ورسالة `CertificateGenerationRequested` في Transaction واحد. يعالج `OutboxWorker` الرسائل بدفعات، ويطالب بكل رسالة بتحديث ذري وقفل مؤقت، ثم يطبق Backoff حتى `Certificates:MaxProcessingAttempts`. يستطيع المعلم إعادة رسالة فاشلة إلى `Pending`.
4. **توليد وتخزين Idempotent:** يولد `CertificatePdfRenderer` ملف A4 أفقيًا عبر QuestPDF. المسار `certificates/{tenantId}/{certificateId}.pdf` حتمي، ويفحص المعالج وجود الملف قبل الرفع. كل القراءة والكتابة تمر عبر `IObjectStorage`.
5. **ترخيص وخطوط صريحة:** يختار التشغيل نوع ترخيص QuestPDF من `Certificates:QuestPdfLicense`. غياب القيمة في Production يمنع بدء API حتى يراجع مالك النشر أهليته القانونية. الخط الافتراضي `Arial` على Windows و`DejaVu Sans` على Linux، وكلاهما قابل للضبط.
6. **رموز عامة غير قابلة للتخمين:** رمز الشهادة 256-bit؛ يُخزن SHA-256 للبحث، وتُحمى النسخة الخام بـASP.NET Core Data Protection حتى يمكن إعادة رابط الشهادة لصاحبها. لذلك يجب أن تكون مفاتيح Data Protection دائمة في الإنتاج.
7. **مشاركة ولي الأمر منفصلة:** ينشئ الطالب رمزًا مستقلًا مخزنًا كهاش، تنتهي صلاحيته بعد `Certificates:ParentShareDays` (الافتراضي 7). `PublicResultResponse` لا يعيد معرّفات داخلية أو إجابات الطالب أو الإجابات الصحيحة؛ يعيد الاسم، الاختبار، الدرجة، حالة الاجتياز، تاريخ الإكمال، عناوين المراجعة، ورابط الشهادة إن كانت جاهزة.

## النتائج

- نجاح المحاولة لا يتراجع عند تعطل توليد PDF، والفشل مرئي وقابل لإعادة المحاولة.
- إعادة الطلب أو إعادة تشغيل العامل لا تنشئ شهادة أو ملفًا ثانيًا.
- قاعدة البيانات لا تحتوي الرموز العامة الخام بنص واضح، لكن استمرار روابط الشهادات يتطلب استمرار مفاتيح Data Protection.
- `OutboxWorker` يعمل داخل عملية API في الـMVP؛ يمكن فصله لاحقًا دون تغيير العقد أو الجداول.
- تفعيل `Storage:Provider=S3` في الإنتاج ما زال يتطلب تنفيذ موصل S3 الفعلي؛ التنفيذ الحالي يفشل مبكرًا بدل تخزين صامت غير دائم.
