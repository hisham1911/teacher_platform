# ADR 005 — نشر الاختبارات: نسخ منشورة Immutable ورمز وصول عام

**الحالة:** Accepted  
**التاريخ:** 2026-08-03

## السياق

Phase 3 تتطلب نشر الاختبارات للطلاب عبر رابط عام. المتطلبات المتعارضة:

- الطالب يجب أن يرى **نفس الأسئلة** التي نشرها المعلم، حتى لو عدّل المعلم المسودة لاحقًا.
- المعلم يحتاج تحرير المسودة بعد النشر (إضافة/إزالة أسئلة) دون كسر الاختبار المنشور.
- الوصول العام يجب ألا يكشف أسئلة أو خيارات أو إجابات قبل بدء المحاولة (Phase 4).
- الرابط العام يجب ألا يكون قابلًا للتخمين التسلسلي.

## القرار

- **فصل الهوية عن المحتوى:** `Quiz` يحمل الحالة والمؤشرات فقط؛ المحتوى في `QuizVersion` Immutable.
- **مؤشران مستقلان:** `CurrentDraftVersionId` (قابل للتعديل) و`CurrentPublishedVersionId` (لا يتغير إلا عبر نشر جديد).
- **النشر عملية ذرّية:** التحقق من `IsValid` + حد الاختبارات النشطة، ثم نقل المؤشر وتغيير `Status` إلى `Published` في معاملة واحدة.
- **`QuizVersionItem` يثبّت `QuestionVersionId`:** النسخة المنشورة تشير إلى نسخ أسئلة محددة (ADR 004)، فتعديل السؤال لاحقًا لا يؤثر في المنشور.
- **`PublicCode`:** GUID-only (32 حرفًا hex) يُولّد عند الإنشاء، غير قابل للتخمين التسلسلي، ويُستخدم في `/q/{publicCode}` و`GET /api/v1/public/quizzes/{publicCode}`.
- **الـEndpoint العام metadata-only:** يعيد العنوان والوصف والتعليمات وعدد الأسئلة وإجمالي الدرجات ونسبة النجاح ووضع الوقت والثيم — **بدون** أسئلة/خيارات/إجابات. الأسئلة تُسلَّم فقط عند بدء المحاولة في Phase 4.
- **الوصول العام مقيد بالحالة:** `Draft` و`Archived` يعيدان `404` — فقط `Published` متاح.

## البدائل

- **نسخة واحدة مع علم IsPublished:** تعديل المسودة بعد النشر سيكسر الاختبار المنشور أو يتطلب منع التعديل كليًا.
- **PublicCode تسلسلي (1, 2, 3…):** قابل للتخمين والعدّ — مرفوض أمنيًا.
- **كشف الأسئلة في الـEndpoint العام:** يسمح بالغش قبل بدء المحاولة — مرفوض.
- **Snapshot كامل JSONB للاختبار المنشور:** يكرر البيانات ويفقد تكامل المراجع مع QuestionVersions.

## النتائج

- تعديل المسودة بعد النشر آمن: المنشور يبقى يشير إلى النسخة القديمة حتى نشر جديد.
- إعادة النشر تنشئ `QuizVersion` جديدة برقم تزايدي — تاريخ النشر محفوظ بالكامل.
- صفحة الهبوط العامة `/q/:publicCode` تعرض metadata فقط مع ملاحظة أن Player يأتي في Phase 4.
- `Checksum` على `QuizVersion` يتيح كشف أي تعديل خارجي على النسخ المنشورة.

## قيود

- لا يوجد "إلغاء نشر" (Unpublish) — الأرشفة هي البديل، وتعيد `404` للرابط العام.
- لا يوجد تحديث تلقائي للأسئلة المثبتة عند تحديث السؤال الأصلي — المسار اليدوي: إزالة العنصر وإعادة إضافته في المسودة ثم نشر جديد (شارة "يوجد تحديث" تُعرض في واجهة التعديل).
