# ADR 006 — حدود الاستخدام: سقف الاختبارات النشطة لكل Tenant

**الحالة:** Accepted  
**التاريخ:** 2026-08-03

## السياق

المنصة متعددة المستأجرين (SaaS). بدون حدود، يمكن لمستأجر واحد إنشاء عدد غير محدود من
الاختبارات النشطة، مما يستهلك موارد مشتركة (تخزين، فهارس، استعلامات قائمة) ويصعّب
التسعير المستقبلي القائم على الخطط.

المطلوب في Phase 3: فرض حد أقصى للاختبارات **النشطة** (غير المؤرشفة) لكل Tenant، مع
قابلية الإعداد دون تغيير الكود.

## القرار

- **التجريد:** `IQuizLimitService` في Application — `Task EnsureCanCreateAsync(Guid tenantId, CancellationToken)` يرمي `QuizLimitExceededException` عند تجاوز الحد.
- **التنفيذ:** `QuizLimitService` في Infrastructure يعدّ الاختبارات غير المؤرشفة عبر `IQuizRepository` ويقارنها بالحد.
- **الإعداد:** `QuizLimitOptions` — `Quiz:MaxActivePerTenant` في `appsettings.json` (افتراضي **50**). قيمة `0` أو سالبة = بلا حد.
- **نقطة الفرض:** عند **الإنشاء** فقط (وليس عند النشر) — الأرشفة تحرر السعة فورًا لأن العدّ يستثني `Archived`.
- **الاستجابة:** `GlobalExceptionHandler` يحوّل `QuizLimitExceededException` إلى `403` problem+json برسالة واضحة تتضمن الحد الحالي.

## البدائل

- **الفرض عند النشر بدل الإنشاء:** يسمح بتراكم مسودات غير محدودة ثم يفاجئ المستخدم عند النشر — تجربة أسوأ.
- **حد ثابت في الكود:** يتطلب إعادة نشر لتغييره — مرفوض لصالح الإعداد.
- **جدول Quotas لكل Tenant:** مرونة أعلى (خطط مختلفة) لكنه YAGNI الآن — يُؤجل حتى ظهور التسعير الفعلي؛ التجريد `IQuizLimitService` يسمح باستبدال التنفيذ دون تغيير الاستدعاءات.
- **العدّ عبر استعلام خام `$wpdb`-style:** يتجاوز Global Query Filters — مرفوض؛ العدّ يمر عبر الـRepository لضمان عزل الـTenant.

## النتائج

- حد افتراضي معقول (50) يحمي الموارد المشتركة دون التأثير في الاستخدام الطبيعي.
- تغيير الحد = تغيير إعداد فقط، ويمكن تخصيصه لكل بيئة (`appsettings.{Environment}.json`).
- رسالة `403` الواضحة تتيح للواجهة عرض "أرشف اختبارات قديمة أو تواصل مع الدعم".
- التجريد يفتح الباب مستقبلًا لـQuota لكل Tenant أو لكل خطة دون تغيير `QuizService`.

## قيود

- الحد حاليًا **عالمي** لكل الـTenants (لا تخصيص لكل مستأجر).
- العدّ يشمل `Draft` و`Published` (كل ما ليس `Archived`) — مسودة منسية تستهلك سعة.
- `QuizService` يمرر `Guid.Empty` كـtenantId لبعض فحوص الحد الداخلية معتمدًا على
  Global Query Filters للعزل — موثق كـsmell مقبول مؤقتًا؛ التشديد الكامل يتطلب تمرير
  `TenantId` صراحة في كل مسارات الحد.
